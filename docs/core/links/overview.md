# links 模块

`Links.json` 记录部署目标、Store 来源、实际方式和目录拷贝的文件清单。期望状态由档案提供。账本无法读取或解析时，部署写入暂停，原文件保留供诊断。

- 新部署使用独立副本，阻止游戏目录写入影响 Store。旧硬链接、目录联接和符号链接继续按文件身份或链接目标核对。副本依赖已记录的相对路径和内容比对。
- 目标已缺失时可清理过期记录或按档案重新部署。遇到未知目标、额外文件、内容修改或路径越界时停止。目录清理只移除已确认的文件与空目录。
- Windows 的旧账本可能保留不同的目录大小写。核对目标时先比较父目录的实际路径；名称大小写不同时还要确认目录中指向同一条目。
- 复制使用独占创建，失败时清理由本次创建的文件与目录。同路径替换先临时保留旧目标，失败时恢复，成功写入账本后清理旧目标。
- 索引写入失败可以在同一进程重试。进程异常退出可能留下临时旧目标，模块没有跨进程事务恢复。
