# shell

## 职责

包住内容区的外壳：标题栏、侧栏、任务中心、开发者浮层，以及按当前页挂载内容的滚动容器。不持有业务状态，所有数据来自 `ui::Ui` 的 signal；页面函数放 `pages`。

## 结构

| 文件 | 职责 |
| --- | --- |
| `shell.rs` | 模块根；`content()` 遍历导航表生成 `when` 区域 |
| `shell/nav.rs` | 导航数据的唯一来源：id、locale key、图标、分组、页面/动作 |
| `shell/sidebar.rs` | 宽树与窄图标栏、折叠开关、组头、页脚启动键与版本行 |
| `shell/title_bar.rs` | 标题栏：品牌图标、产品名、版本与窗口控件 |
| `shell/statusline.rs` | 自动消失的操作反馈 |
| `shell/keyboard.rs` | 应用窗口内的分区键位与弹层焦点交接 |
| `shell/task_center.rs` | 右侧可展开的任务入口和侧抽屉 |
| `shell/dev.rs` | 五连点版本行打开的开发者浮层 |

## 导航模型

- 模组搜索入口在远程模组与 Nexus 页面内，侧栏用于切页和启动游戏。
- `NavKind::Page(fn(&Ui) -> AnyElement)` 进内容区；`NavKind::Action(fn(&Ui))` 只执行副作用（页脚启动）。
- `group: Some("mods")` 的条目在宽模式归到 `GROUPS` 的组头下；`page` 存的是 id，不是索引，重排不影响页头。
- `title(id)` 对组内条目返回「父 / 子」，其余返回自身 key；找不到时回退 settings。
- 组头只翻 `nav_closed_group`，不写 `page`；组内页面被折叠时仍保持选中。

## 渲染规则

- Cuprum 品牌图标源文件在 `art/cuprum/`。用 Lua 脚本的 `ridge` 方案重绘时，将导出的 32×32 PNG 用于标题栏，将 8 倍最近邻预览用于 `nsh.json` 指定的打包图标。
- 宽 176px。组头以箭头表示展开状态，组收起且内有当前页时在箭头旁显示绿色方点。子项以低对比分支线相连，选中底色和绿色标记收在缩进内。顶层条目保留靠外侧的选中标记。
- 窄 44px。组边界用低对比分隔线，选中项有左描边，图标悬停和键盘聚焦时显示页面名称。
- 页脚：启动键始终显示，版本行只在宽模式；版本行五连点在 3 秒窗口内计数。
- 折叠状态、组开关都在 `Ui` 的内存 signal，不落盘。
- 栏宽和分组展开通过布局弹簧过渡，切页时选中标签淡入。

## 任务入口

- 右侧入口始终保留任务图标，悬停或键盘聚焦时向左展开。通过点击或键盘命令打开抽屉。新增卡片不改变打开状态。
- 任务抽屉按需处理、进行中、本次失败排序，支持 Esc 和点击遮罩关闭。任务计数排除仅有下载进度的操作。
- 通用操作反馈短暂显示。Bridge 状态和相关入口在多人游戏、本地模组与任务卡里呈现。

## 键盘导航与焦点

- 侧栏的 `h` / `l` 折叠或展开分组，`Enter` 激活。本地行的 `Enter` 展开详情，`l` 打开操作菜单，`s` 切换该行已有的批量复选框。任务卡的 `l` 进入操作按钮，`h` 回到卡片。普通 Tab 顺序继续到达现有控件。
- 单键命令的捕获跟随可见焦点。跨区的 `F6` 使用 NSH 的非编辑条件。前缀提示随 `g` 出现，第二键、取消或失焦后即时消失。任务抽屉内的前缀只用于首尾跳转。
- 侧栏按导航 ID 找回项目，本地模组按来源路径找回行，任务按卡片 ID 找回。项目消失时选原位置后面的项，集合缩短则选末项，空集合回到工具栏或关闭按钮。焦点目标超出视口时由当前滚动容器立即滚入视野。
- 键盘焦点描边用主题强调色，三个缩放档分别为 2、2、3 个界面像素。描边即时切换，行或卡片内部控件聚焦时外层有浅底提示。侧栏、抽屉和详情仍使用各自原有动效。
- 抽屉和安装修复、删除确认通过 NSH 模态焦点范围交接。删除确认首先聚焦「取消」，执行期间焦点留在确认范围内。卡片上的安装操作须单独激活现有按钮。

## 边界与失败模式

- 侧栏不读 Hub、不联网、不写盘。
- `NAV` 是 `static`，条目顺序就是侧栏顺序；新增页面必须同时补 `pages` 函数与 locale key，否则 `t!` 会渲染键名。
