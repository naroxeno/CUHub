## 安装说明

- manifest 会优先按 `asset` 精确匹配 release 资产；New Firearms、Gun Minigame、CUShocker、Custom Structures 等有多个资产的仓库已经锁定文件名。
- CUShocker 的 zip 同时带 OpenShock 桌面程序；CUHub 的安装器会按 `BepInEx/plugins` 前缀只取插件部分。
- CT 的 release 自带 `CUCoreLib.dll`；manifest 已声明 CUCoreLib 依赖，安装时会先要求安装 CUCoreLib，并跳过包内副本。
- Bark 是目录型模组，会落到 `Plugins/Bark/`；BepInEx 5 会递归扫描插件目录。
- Custom Structures 依赖 CUCoreLib；CUAP 的 `.apworld` 与 YAML 是 Archipelago 服务端文件，不在 CUHub 的安装范围内。
- Russian Voice Over 约 106 MB，第一次安装会明显比其它条目慢。

## 未收录

- `blue-star-fox/CU-SACE`：release 资产名是 `SAC-V1.6.10.dll`，README 说插件文件应为 `SAC.dll`，且是 host-only 反作弊；未验证，先不放进可用表。
- 有仓库但没有 release 资产：Xeron Online、guardian-drone、wayfarer、CU_emotes、CasUnkGetSomePersonality、All-Characters-Unlock、Tutorial-Unlock、harry0805 addons、Keheck Disease Mod、CasualtyCenter、tigerLin 汉化等。
- `OptimisedCraftingSystem` 有 release 但没有资产；Korean Patch 是 XTMPi 布局，不是 BepInEx。
- 这里只验证了 release 资产存在与清单解析通过，没有逐个进入游戏实测。

## 用法

本地兜底：备份后把 `github-mods.manifest.json` 复制到 `~/.local/share/CUHub/Sources/manifest.json`。远程方式：把它上传到 `naroxeno/CUHub-Store` 根目录并改名为 `manifest.json`。
